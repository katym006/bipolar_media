# Bipolar Media

Онлайн-медиа о биполярном расстройстве: статьи, скрининговые тесты, специалисты и трекер настроения.

## Требования

- Ruby **3.4.3** (версия указана в `.ruby-version`)
- Bundler
- SQLite 3

Отдельно устанавливать сервер базы данных не нужно: в разработке используется SQLite, файл базы создаётся в `storage/development.sqlite3`.

## Запуск проекта локально

1. Клонируйте репозиторий и перейдите в каталог проекта:

   ```bash
   git clone https://github.com/katym006/bipolar_media.git
   cd bipolar_media
   ```

2. Установите зависимости:

   ```bash
   bundle install
   ```

3. Подготовьте базу данных и выполните миграции:

   ```bash
   bin/rails db:prepare
   ```

4. (Необязательно) Загрузите демонстрационные данные, если они нужны для локальной проверки:

   ```bash
   bin/rails db:seed
   ```

5. Запустите Rails-сервер:

   ```bash
   bin/rails server
   ```

6. Откройте приложение в браузере: http://localhost:3000.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

## Административная панель

HTML-панель администратора находится по адресу `/admin` (после запуска — http://localhost:3000/admin). Она отображает количество записей и последние статьи, скрининговые тесты и специалистов. Из панели можно перейти к существующим Rails-страницам создания, просмотра, редактирования и удаления записей.

Панель использует серверные представления ERB и обычные Rails-контроллеры; отдельный JavaScript-фреймворк или frontend-приложение не требуется.

### Выдать роль администратора

Сначала зарегистрируйте пользователя через обычную форму регистрации приложения. Затем выполните:

```bash
bin/rails console
```

В консоли Rails укажите email зарегистрированного пользователя:

```ruby
user = User.find_by!(email: "your_email@example.com")
user.update!(access_role: "admin")
user.reload.access_role
```

Замените `your_email@example.com` на фактический адрес. Последняя команда должна вернуть `"admin"`. Затем войдите под этим пользователем и откройте `/admin`.

Не назначайте роль администратора через открытую форму регистрации. Проверка роли выполняется сервером в `Admin::BaseController`; действия CRUD также должны проходить проверки CanCanCan в соответствующих контроллерах.

## Полезные команды

Запустить тесты:

```bash
bin/rails test
```

Посмотреть доступные маршруты:

```bash
bin/rails routes
```

Проверить маршрут панели администратора:

```bash
bin/rails routes -g admin
```

Открыть Rails-консоль:

```bash
bin/rails console
```

## Основные разделы

- **Статьи** — просмотр и управление статьями.
- **Скрининговые тесты** — просмотр тестов и управление ими в соответствии с правами доступа.
- **Специалисты** — каталог специалистов.
- **Трекер настроения** — создание записей и просмотр истории настроения.

Доступ к действиям зависит от авторизации пользователя и его роли.

## Примечания

- Для локальной разработки используйте команды из корня проекта.
- Если команда `bin/rails` не запускается, проверьте установленную версию Ruby и выполните `bundle install`.
- Не добавляйте секреты и локальные файлы базы данных в коммиты.
