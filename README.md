# Bipolar Media

Онлайн-медиа о биполярном расстройстве: статьи, скрининговые тесты, специалисты и трекер настроения.

## Требования

- Ruby **3.4.3** (версия указана в `.ruby-version`)
- Bundler
- SQLite 3

Отдельно устанавливать сервер базы данных не нужно: в разработке используется SQLite, файл базы создаётся в `storage/development.sqlite3`.

## Запуск проекта локально

1. Клонируйте репозиторий и перейдите в каталог проекта:

   ```bash
   git clone https://github.com/katym006/bipolar_media.git
   cd bipolar_media
   ```

2. Установите зависимости:

   ```bash
   bundle install
   ```

3. Подготовьте базу данных и выполните миграции:

   ```bash
   bin/rails db:prepare
   ```

4. (Необязательно) Загрузите демонстрационные данные, если они нужны для локальной проверки:

   ```bash
   bin/rails db:seed
   ```

5. Запустите Rails-сервер:

   ```bash
   bin/rails server
   ```

6. Откройте приложение в браузере: [http://localhost:3000](http://localhost:3000).

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

## Полезные команды

Запустить тесты:

```bash
bin/rails test
```

Посмотреть доступные маршруты:

```bash
bin/rails routes
```

Открыть Rails-консоль:

```bash
bin/rails console
```

## Основные разделы

- **Статьи** — просмотр и управление статьями.
- **Скрининговые тесты** — просмотр тестов и управление ими в соответствии с правами доступа.
- **Специалисты** — каталог специалистов.
- **Трекер настроения** — создание записей и просмотр истории настроения.

Доступ к действиям зависит от авторизации пользователя и его роли.

## Примечания

- Для локальной разработки используйте команды из корня проекта.
- Если команда `bin/rails` не запускается, проверьте установленную версию Ruby и выполните `bundle install`.
- Не добавляйте секреты и локальные файлы базы данных в коммиты.
